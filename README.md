# Clinic Ready

This project is separated from Clinic_Ready_Final_Scenarios_Fixed.html without changing its educational data or application logic.

## Edit locally on Mac
1. Extract the ZIP and open the clinic-ready folder in Visual Studio Code (File > Open Folder).
2. Edit modules.js for content, style.css for appearance, script.js for functionality, or index.html for the page shell.
3. Save with Command+S. Preview index.html in a browser, or use the Live Server extension.
4. Keep all four website files together. Do not rename them individually.

## Publish with GitHub Pages
1. Sign into GitHub in VS Code. Install Git if VS Code requests it.
2. Open Source Control, initialize the repository if needed, stage files, and commit with a message such as Initial website.
3. Choose Publish to GitHub (or Publish Branch), name the repository clinic-ready, and choose Public for free GitHub Pages. Review the files before making them public.
4. On github.com open the repository, then Settings > Pages. Under Build and deployment choose Deploy from a branch, main, / (root), and Save. If your default branch has another name, select that branch instead.
5. Wait for deployment. The Pages settings will show the public URL, typically https://YOUR-USERNAME.github.io/clinic-ready/.
6. Test all modules, quizzes, answer reveals and feedback before sharing. Browser-local progress does not automatically sync or send feedback to you.

## Updates
Edit and save, stage and commit changes in Source Control, then push/sync. GitHub Pages redeploys the site at the same URL.
